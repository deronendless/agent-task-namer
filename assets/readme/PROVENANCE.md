# README comparison artwork

The English and Chinese comparisons are illustrative task lists, not client screenshots. They show the same five fictional tasks in the same order. All example creation dates are September 4, 2026 in Asia/Shanghai, represented as `260904`.

`background.png` was generated with the built-in Codex ImageGen tool. `comparison.html` supplies all final text, task rows, emoji, dates, separators, and layout deterministically; it accepts `?lang=en` and `?lang=zh`. Export each language at a 1600 × 1000 viewport after `window.__ready` resolves to true. System fonts and emoji rendering can vary by operating system.

Final exports: `before-after-en.png` and `before-after-zh.png`.

In the upper RIGHT quarter only, make a small, exquisite three-dimensional still-life of slim rounded paper task cards: a few softly staggered ivory cards gently resolve into a precise aligned stack with small muted eucalyptus green index tabs. A single muted amber tab among the earlier cards can suggest varied task types. Studio daylight, subtle contact shadows, restrained natural depth, crisp tactile edges. Decorative still-life occupies at most 22 percent of the canvas, fully in the top right region and not touching edges. Professional open-source product editorial aesthetic, airy, understated, clean. NO text, NO letters, NO numbers, NO logos, NO interface chrome, NO icons, NO watermark. No huge glow, no glassmorphism, no dramatic gradients, no neon, no people. This image is only a background asset, not a completed mockup: exact titles and UI will be rendered separately.
